# In Office Exercise Station

During this 10 week project, in a team of 5 we had to create an interactive system with the topic "sport". After initial brainstorming we decided to focuse on office workers, who often, due to the sedentary lifestyle, lack exercises in their everyday life.

The project consisted of a lot of research and design iterations, which can be read about in the report. The final system was an archery game where to shoot and aim the bow, the users need to pull on a resistive band. 

I've mainly worked on the pressure sensor, which was self-built using a copper tape and velostat to provide a uniform pressure measurements across all directions pulling as well as to enable analog measurements of current pulling strength. I have also helped with the gyroscope integration as well as communication between the game and the sensors.
